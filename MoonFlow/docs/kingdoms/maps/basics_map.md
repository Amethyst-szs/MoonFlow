# Kingdom Editor - Map2d
MoonFlow supports modifying and creating custom Map2Ds. These are an illustration of the kingdom's layout, used in-game to show Power Moon locations, as well as other items of interest like checkpoints.

When using the Kingdom Editor, you can hover over any Power Moon icon on the map to see its name. When hovering over a Power Moon in the content editor's Power Moon list, the icon will be highlighted on the map itself to help you quickly locate its position.

Note that the Power Moon icon positions are based on the "[Map Position](kingdoms/moon_list.md#Position)" field, not the in-game position of the object. Make sure to set your map positions to keep the map accurate!

## Creating New Maps
Creating new maps is a fairly in-depth process, but is made substantially easier with MoonFlow! There's a [video tutorial on this here](https://youtu.be/KqcZTH-KYOs) and you can [read a written guide here](kingdoms/maps/creating_new_maps.md).
